# Восстановление Sergек / Sergек жобасын қалпына келтіру

## На русском языке

Архив финала от 17 октября 2026 года сохраняет исходный код после финальных изменений, модели с лицензиями и SHA-256, тесты, плагин Moodle, локальную лабораторию и материалы защиты.

- Код: [GitHub](https://github.com/Mikosh001/Qostanai-AI-Industry-Hackathon-2026).
- Установщик Windows, полный комплект защиты и контрольные суммы: [архив финала](https://github.com/Mikosh001/Qostanai-AI-Industry-Hackathon-2026/releases/tag/hackathon-final-2026-10-17).
- Сайт подготовки: папка `final/`; опубликованная копия — https://sergek-final.vercel.app/.
- Редактируемый проект DemoBuilder, исходники оформления и видео включены в `Sergek-Final-Defense.zip` в релизе. Внутри архива сохранён `DemoBuilder/source/Render.cmd` для повторного рендера.

### Продолжить разработку

Нужны Windows x64, Git, Python 3.12 x64, Node.js 24 и .NET 8 SDK. Первый запуск требует интернет для установки зависимостей и лаборатории Moodle. Общесистемные инструменты устанавливаются отдельно.

```powershell
git clone https://github.com/Mikosh001/Qostanai-AI-Industry-Hackathon-2026.git
cd Qostanai-AI-Industry-Hackathon-2026
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Setup-Dev.ps1 -Python python
.\.venv\Scripts\python.exe -m pip install -r tests/requirements.txt
.\.venv\Scripts\python.exe -m pytest tests -q
npm.cmd run test:desktop
npm.cmd run build
npm.cmd run desktop
```

Для создания установщика:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Build-Windows.ps1 -Installer
```

Сначала установите готовый Windows-пакет из релиза или соберите его. Затем выполните `Start-Sergek-Demo.cmd`: скрипт подготовит локальную лабораторию Moodle и запустит приложение. Лаборатория создаёт собственные настройки и ключи. Порт 3308 используется базой, веб-порты определяются настройками лаборатории. Инструкция по вопросам теста: [MOODLE-QUIZ-GUIDE.md](MOODLE-QUIZ-GUIDE.md); демонстрационные вопросы: [demo-questions.gift.txt](demo-questions.gift.txt).

### Презентации и демо

В `final/` лежат русская и казахская презентации PPTX со встроенным 40-секундным видео на слайде 4. Откройте PPTX в настольном PowerPoint и включите показ слайдов. Сохранённый PPTX работает без интернета. Для HTML откройте `final/START.html`, сохраняя рядом папку `assets`. PDF — статичный резерв. `final/Speech-RU.txt` содержит речь для двух спикеров.

Статический сайт можно заново разместить на Vercel, указав корнем проекта `final/`. Аккаунт и привязка Vercel настраиваются заново; учётные данные в репозитории не хранятся.

### Что восстанавливается заново

`node_modules`, виртуальное окружение Python, .NET SDK, скачанные Moodle/PHP/MariaDB, промежуточные сборки и кэши в архив исходников не входят: их создают установочные скрипты. Модели сохранены в `models/`; `scripts/download_models.py` проверяет их контрольные суммы.

Личные записи камеры и микрофона, эталоны лиц, журналы реальных сеансов, базы с учётными данными, приватные ключи и токены не опубликованы. Лаборатория разворачивается с чистыми тестовыми данными. Демо показывает реальный интерфейс и контролируемый сценарий правила телефона; оно не является измерением точности физического детектора. Финальные файлы содержат только разрешённые к публикации материалы.

## Қазақ тілінде

2026 жылғы 17 қазандағы архивте соңғы код, лицензиялары мен SHA-256 мәндері бар AI модельдері, тесттер, Moodle плагині, локалды зертхана және қорғау материалдары сақталған.

Жобаны GitHub-тан `git clone` арқылы жүктеп, жоғарыдағы командаларды орындаңыз. Windows x64, Python 3.12, Node.js 24, Git және .NET 8 SDK қажет. Алғашқы орнату кезінде интернет керек. `scripts/Setup-Dev.ps1` тәуелділіктерді орнатады, `scripts/Build-Windows.ps1 -Installer` орнатқышты жинайды. Дайын орнатқыш GitHub релизінде де сақталған.

Moodle демонстрациясын іске қосу үшін дайын бағдарламаны орнатып, `Start-Sergek-Demo.cmd` файлын ашыңыз. Зертхана жаңа баптаулар мен кілттер жасайды. Сұрақтарды қосу нұсқаулығы — `docs/MOODLE-QUIZ-GUIDE.md`.

`final/` папкасында қазақша және орысша презентациялар, 40 секундтық видео, екі спикерге арналған мәтін және дайындық сайты бар. PPTX видеосы файлдың ішіне енгізілген: компьютердегі PowerPoint арқылы интернетсіз көрсетуге болады. HTML үшін `assets` папкасын бірге сақтаңыз. Өңделетін DemoBuilder жобасы релиздегі `Sergek-Final-Defense.zip` архивінде бар.

Жеке камера жазбалары, бет эталондары, емтихан сессияларының деректері, құпия кілттер мен токендер GitHub-қа салынбаған. Уақытша орталар мен кэштер қайта жасалады; локалды Moodle таза тест деректерімен құрылады.
