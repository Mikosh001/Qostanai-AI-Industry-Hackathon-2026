# Moodle-ға тест қосу

Осы компьютердегі Moodle: **https://localhost/**. Курс: **Sergек — таныстыру курсы**. Moodle-дың мұғалім тіркелгісі және Sergек панелінің құпиясөзі екі бөлек кіру тәсілі.

## 1. Ортаны ашу

Жұмыс үстеліндегі **Sergек — таныстыру** таңбашасын немесе жобадағы **Start-Sergek-Demo.cmd** файлын ашыңыз. Бұл Moodle, HTTPS хаб және Sergек қосымшасын қосады.

Браузерде `https://localhost/` ашыңыз. Moodle мұғалімінің логині — `testteacher`. Оның құпиясөзі іске қосқыш көрсететін жеке **Demo-login.txt** файлындағы **Moodle мұғалімінің құпиясөзі** жолында. Осы workspace-та файл `work/local-moodle/Demo-login.txt` ішінде орналасқан. Бұл жергілікті тіркелгі осы таныстыру курсын өңдеуге құқылы.

## 2. Жаңа тест құру

1. **My courses → Sergек — таныстыру курсы** бөліміне өтіңіз.
2. **Edit mode** қосыңыз.
3. Қажетті бөлімде **Add an activity or resource → Quiz** таңдаңыз.
4. Тесттің атауын, қажет болса уақытын және әрекет санын белгілеңіз.
5. **Extra restrictions on attempts** бөлімін ашып, **Require Sergek Proctor** белгісін қосыңыз. Тестті осы плагин қорғайды.
6. **Save and display** басыңыз.
7. **Questions → Add → a new question** арқылы сұрақ құрыңыз. Сұрақ мәтінін, жауаптарын, дұрыс жауаптың бағасын сақтаңыз. Дайын сұрақтар болса **Add → from question bank** қолданыңыз. Соңында максималды бағаны сақтаңыз. [Moodle: тестке сұрақ қосу](https://docs.moodle.org/405/en/Building_Quiz).

## 3. Бес дайын сұрақты жүктеу

Жобадағы **docs/demo-questions.gift.txt** файлында бағдарламалау негіздері туралы бес қазақша сұрақ бар.

Осы компьютердегі курста **Бағдарламалау негіздері — 5 сұрақ** тесті дайын: бес сұрақ импортталып, тестке қосылған, Sergек ережесі қосулы. Оны таныстыруға қолдануға болады.

Курстың **More → Question bank** бөлімін ашып, сұрақтар банкіндегі мәзірден **Import** таңдаңыз. **GIFT format** белгілеңіз, **Choose a file → Upload a file** арқылы дайын файлды жүктеңіз, **Import** басыңыз. Moodle бес сұрақты көрсеткенде **Continue** басыңыз.

Содан кейін тесттің **Questions → Add → from question bank** бөлімінде **Sergек бағдарламалау** санатын таңдаңыз, **Apply filters** басыңыз. Бес сұрақты белгілеп, **Add selected questions to the quiz** басыңыз. **Shuffle** қоссаңыз, сұрақтардың реті өзгереді.

GIFT файлында `=` дұрыс жауапты, `~` қате жауапты білдіреді; `{TRUE}` және `{FALSE}` дұрыс/бұрыс сұрақтарына арналған. Файл UTF-8 түрінде сақталуы керек. [Moodle: GIFT форматы](https://docs.moodle.org/405/en/GIFT_format).

## 4. Студент қалай кіреді

Студент сұрақ файлын немесе тест URL-ін енгізбейді. **Sergек → Moodle-ға кіру → студент логині → курс → қажетті тест**. Қорғалған тест таңдалғанда фотоға дайындық автоматты ашылады. **Келісім → Фотоға өту → Фотоға түсіру → Емтиханды бастау**. Қорғаныс бастау батырмасымен іске қосылады.

Жауаптар Moodle-да бағаланады. **Submit all and finish** орындалғанда Moodle сервері Sergек-ке хабарлайды; агент сессияны автоматты аяқтайды. Мұғалім камера/экран/дыбыс оқиғаларын бөлек Sergек панелінен қарайды.

Курс осы локалды студентке бұрыннан ашылған. Университетте жаңа студенттерге курстың **Participants → Enrol users** бөлімі арқылы қолжетімділік беру қажет. Университеттің Moodle-ына қосуды оның әкімшісі орындайды: плагин, HTTPS хаб, ортақ кілт және рұқсат етілген домендер бір рет бапталады.

## Жиі кездесетін жағдайлар

- **Тестке жаңа сұрақ қосылмайды:** тестте тапсырылған әрекеттер болуы мүмкін. Тарихты өшірудің орнына жаңа тест жасаңыз.
- **Тест Sergек-ті ашпайды:** сол тестте **Require Sergek Proctor** қосылғанын тексеріңіз.
- **Қорғалған тест кәдімгі браузерде ашылмайды:** студент оны Sergек ішіндегі Moodle арқылы бастайды. Сервер белсенді прокторинг сессиясын талап етеді.
- **Жаңа тест студентке көрінбейді:** тесттің көріну күйін, ашылу уақытын және курсқа тіркелуін тексеріңіз.

Кіру деректері source архивіне кірмейді. Басқа компьютерде іске қосқыш жаңа жеке тіркелгілерді дайындайды.
