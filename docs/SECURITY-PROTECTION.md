# Антивирусная защита и целостность Sergек / Sergек антивирустық қорғанысы

Проверка: 13 октября 2026 года, Windows 11 build 26200. Результаты ниже относятся к указанным испытаниям и сборке на этом ноутбуке.

## На русском языке

### Что добавлено

Sergек использует антивирусный движок **Microsoft Defender**, установленный в Windows, и собственный контроль целостности экзаменационного приложения. Это два разных уровня: Defender проверяет вредоносное ПО, Sergек проверяет условия допуска и изменение своих компонентов.

| Риск | Реализованная защита |
|---|---|
| Отключённый или устаревший Defender | Проверка службы/антивируса, real-time, behavior, on-access, IOAV, Tamper Protection, возраста сигнатур и активных угроз через WMI |
| Выключение защиты после начала теста | Фоновое обновление каждые 10 с; независимый watchdog контролирует известное небезопасное состояние и устаревание статуса |
| Подмена native helper до его запуска | Electron сверяет весь bootstrap guard с манифестом из защищённого ASAR до запуска процесса |
| Подмена backend, интерфейса или AI-модели | SHA-256, размер и точный список файлов; запрет ссылок/reparse points; проверка до запуска backend |
| Изменение проверенного файла во время работы | Открытые read-only handles Windows запрещают запись, удаление и замену; список ресурсов повторно проверяется каждые 10 с |
| Запуск через отладчик, Node/.NET/Python injection | Electron fuses, проверка параметров и переменных окружения, очищенное окружение дочерних процессов, выключенные .NET diagnostics |
| Команда защиты от страницы Moodle или iframe | Привилегированный IPC принимает запросы только от основного frame интерфейса; типы и размер запроса проверяются |
| Ошибочное обвинение студента | AV, блокировки и целостность относятся к техническому аудиту, а не к AI-наблюдениям за поведением |

### Как это работает для пользователя

На главной странице и при подготовке доступен блок безопасности на **қазақша / русском / English**: состояние Defender, защита файлов, обновление статуса и сканирование. Сканирование запускается до экзамена отдельной кнопкой и проверяет каталог установленного приложения. Произвольный путь со страницы не принимается.

Запускается настоящий `MpCmdRun.exe`: путь берётся из системных каталогов, Authenticode-подпись и издатель Microsoft проверяются до выполнения. Используется custom scan с `-DisableRemediation`: Sergек не удаляет файлы самостоятельно. Детальные пути и вывод сканера не отправляются преподавателю. Обычная real-time защита Windows продолжает действовать независимо.

Код результата 0 означает успешный результат сканирования; 2 отображается как требующий внимания, поскольку может означать угрозу **или ошибку**. Остальные ошибки и timeout не отображаются как «чисто». Сканирование асинхронное, ограничено тремя минутами и не выполняется поверх активного защищённого экзамена.

Для строгого допуска статус Defender должен быть свежим (до 45 с), сигнатуры — не старше 7 дней, активные угрозы — отсутствовать. Неизвестное состояние не считается безопасным. Временная недоступность WMI во время экзамена допускает ограниченное окно 45 с; известное отключение не получает такого окна. При потере обязательной защиты сессия останавливается с технической причиной, ограничения освобождаются общим механизмом восстановления. При подтверждённой активной угрозе read locks освобождаются, чтобы не мешать штатной обработке Defender.

Installer устанавливает приложение для компьютера в **Program Files**: обычные пользователи имеют чтение/выполнение. Хэши манифеста закреплены внутри ASAR; включены Embedded ASAR Integrity и OnlyLoadAppFromAsar. RunAsNode, NODE_OPTIONS, CLI inspector и привилегированный file:// выключены фьюзами. Режим разработки остаётся отдельным от hardened-сборки.

### Воспроизведение

Из подготовленного dev-окружения:

```powershell
python -m pytest tests -q
npm run test:desktop
npm run test:ui
.\build\guard\Sergek.Guard.exe --self-test-security
.\build\guard\Sergek.Guard.exe --probe-antimalware
node tests/security-entry-e2e.cjs
node scripts/verify_package.cjs release-v1.6.0/win-unpacked tests/security-package.json
npm audit
python -m pip check
```

`tests/security-native-e2e.cjs` предназначен только для собственной **неиспользуемой unpacked-сборки**: он временно добавляет безвредный файл в её каталог, проверяет реакцию и удаляет fixture в `finally`. Не запускайте его поверх установленного приложения или активного экзамена. Приёмка с реальным телефоном, тачпадом, USB и закрытием программ проводится отдельно после сохранения работы.

### Преимущества для университета и условия внедрения

Преподаватель получает понятную причину технического сбоя, а не ложное обвинение. Администратор видит состояние AV и контролирует неизменность AI, backend и интерфейса. Проверки WMI/сканера вынесены из heartbeat, что проверено параллельными запросами. Это конкретные преимущества архитектуры Sergек; превосходство над OES по общей точности или защите требует одинакового независимого сравнительного испытания.

Периметр: управляемая Windows, штатный Defender, защищённая установка и студент без прав изменения ОС. Это не новый сертифицированный антивирусный движок и не hardware attestation. Пользователь с правами локального администратора, kernel-драйвером или изменённой ОС находится вне гарантируемого периметра. Installer пока не имеет сертификата подписи издателя. Для пилота администратор должен принимать официальный пакет, применять права доступа и проверить целевые сборки Windows. Другие AV-продукты пока не поддерживаются: неизвестный статус не подменяется зелёной отметкой.

## Қазақ тілінде

### Қосылған қорғаныс

Sergек Windows-тағы **Microsoft Defender** антивирусын және өзінің файл тұтастығын бақылау модулін қолданады. Defender зиянды бағдарламаларды тексереді. Sergек антивирустың дайын екенін, емтихан компоненттері өзгермегенін және іске қосу талаптары орындалғанын бақылайды.

- Defender қызметі, нақты уақыттағы және мінез-құлық қорғанысы, файлдарды тексеру, Tamper Protection, сигнатура жасы және белсенді қауіптер тексеріледі.
- Қорғаныс күйі әр 10 секунд сайын жаңарады. Белгілі өшіру немесе 45 секундтан ескі күй тәуелсіз watchdog арқылы бақыланады.
- Guard іске қосылмай тұрып оның барлық bootstrap файлдары тексеріледі. Кейін backend, интерфейс, модельдердің SHA-256 хэші, көлемі және толық тізімі салыстырылады.
- Тексерілген файлдар Windows read lock арқылы өзгерту/жоюдан қорғалады. Артық файл қосу да байқалады.
- Қауіпті debugging, Node/.NET/Python іске қосу параметрлері мен environment injection жолдары шектеледі. Electron фьюздары қосымша қорғаныс береді.
- Moodle беті мен iframe жүйелік командаларды шақыра алмайды; privileged IPC тек негізгі интерфейс frame-ін қабылдайды.
- Бұғаттау мен AV оқиғалары студенттің бұзушылықтары тізіміне емес, **техникалық журналға** түседі.

### Пайдалану

Басты бетте және емтиханға дайындықта үш тілдегі қауіпсіздік блогы бар. Ол Defender күйін, файл қорғанысын және сканерлеу нәтижесін көрсетеді. «Сканерлеу» батырмасы емтиханға дейін қосымшаның өз каталогын тексереді; беттен кез келген файл жолын беру мүмкін емес.

Нақты Microsoft қолтаңбасы тексерілген `MpCmdRun.exe` іске қосылады. Бұл тексеріс файлдарды өздігінен жоймайды. Windows-тың қалыпты real-time қорғанысы бөлек жұмыс істейді. Сканер қатесі немесе timeout «қауіп жоқ» деп көрсетілмейді. Процесс асинхронды, ең көбі үш минут жүреді және белсенді қорғалған емтихан үстінде басталмайды.

Қатаң емтиханға кіру үшін Defender күйі 45 секундтан ескі болмауы, сигнатурасы 7 күннен аспауы және белсенді қауіп болмауы керек. Белгісіз күй қауіпсіз деп қабылданбайды. Міндетті қорғаныс жоғалса, техникалық себеппен сессия тоқтатылады және шектеулер қалпына келтіріледі. Белсенді қауіп расталса, Defender әрекетіне кедергі жасамау үшін файл lock-тары босатылады.

Бағдарлама **Program Files** ішіне компьютерге орнатылады. Қалыпты пайдаланушыға оқу/іске қосу құқығы беріледі. ASAR тұтастығы мен бекітілген манифест, native file lock және IPC тексерісі бірге қолданылады.

### Нақты сынақтар

**273 автотест өтті:** 195 Python, 63 desktop, 15 browser. Оған қосымша **26 native қауіпсіздік тексерісі** өтті. Жасанды AV күйлері тек тест ішінде берілді; Defender баптаулары өзгертілген жоқ.

Дайын жинақтың **1 185 файлы 747 мс** ішінде тексерілді. JS файлын жазуға ашу әрекетін Windows бұғаттады. Өз жинағымызға қауіпсіз сынақ файлын қосқанда `package_integrity_lost` тіркеліп, native guard босатылды. Бұл guard сынағы, толық Moodle емтиханы емес.

Нақты Defender дайын болды: Tamper Protection қосулы, сигнатура жасы 1 күн, белсенді қауіп 0. Қосымша файлдарын сканерлеу `clean`, exit 0 нәтижесін берді. Вирус үлгілері пайдаланылмады; бұл барлық вирусты анықтау дәлдігін өлшемейді.

Сканерлеу/WMI қатар жүргенде **250 IPC сұрауы** орындалды: p95 **13 мс**, ең көбі **19 мс**, lease үзілмеді. Бұл сынақта пайдаланушы бағдарламалары жабылмады, USB/клавиатура/remote шектеулері қолданылмады. Electron-ның **6 кіру сценарийі мен 6 фьюзы** тексерілді; payload-маркер орындалмады.

Нақты Moodle 4.5.15-тегі 5 сұрақ толық тапсырылып, басталу/аяқталу уақыты сақталды. Іске қосылуы **4 406 мс** болды. Бұл source Electron-дағы камера/микрофон/OS қорғанысы өшірілген бағдарламалық сценарий; толық аппараттық қабылдаумен теңестірілмейді.

Толық npm ағашында тексеру сәтінде **0 белгілі advisory** қалды. Жинақтау proxy тәуелділігі жаңартылды. `pip check` тәуелділіктер үйлесімділігін растады; бұл Python/.NET/Windows CVE аудиті емес. Нәтижелер жоғарыдағы JSON файлдарында берілген.

### Артықшылығы және қолдану шегі

Университет антивирус күйін және өзгермеген AI/қосымша файлдарын бір жерден бақылайды. Мұғалім техникалық ақауды студент әрекетінен ажыратады. Қауіпсіздік тексерістері heartbeat-ті бөгемейді. Бұлар Sergек-тің дәлелденген мүмкіндіктері; OES-тен жалпы дәлдігі немесе қорғанысы жоғары деу үшін тең жағдайдағы тәуелсіз салыстыру қажет.

Қорғаныс басқарылатын Windows пен студентте ОС-ты өзгерту құқығы жоқ ортаға арналған. Локалды әкімші, kernel-драйвер немесе өзгертілген ОС бұл кепілдік шегіне кірмейді. Installer әзірге баспагер сертификатымен қол қойылмаған. Нақты телефон, тачпад, USB және толық қорғалған емтиханды қолмен қабылдау бөлек өткізіледі. Басқа антивирустардың статусы әзірге қолдау таппайды.
