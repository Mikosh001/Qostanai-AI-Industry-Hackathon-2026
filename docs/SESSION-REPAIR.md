# Стабильность сессии и посторонние окна — 12.10.2026

Последняя пользовательская сессия прервалась через 12,45 с с причиной `cannot_restore_exam_focus`. Перед остановкой Windows сообщала об окне Sergек на переднем плане. Старый обработчик через 400 мс принимал `BrowserWindow.isFocused() === false` за потерю защищённого окна. При встроенном Moodle и собственных диалогах Electron это приводило к ошибочному завершению и снятию ограничений.

Исправления:

- Проверяется реальное foreground-окно Windows: основной HWND, его root owner или точный PID основного процесса экзамена. Имя приложения и доверие к вспомогательным процессам не дают права считаться окном экзамена.
- При настоящей потере фокуса выполняется возврат. Через 4 с результат перепроверяется; длительная неподтверждённая потеря защиты по-прежнему останавливает экзамен.
- Короткие переходы фокуса, подготовка страницы и ответы от уже завершённой сессии не запускают ошибочную остановку. Параллельные причины остановки обрабатываются одной операцией.
- Kiosk, защита изображения и положение поверх окон включаются перед активацией native guard. Передний посторонний процесс проверяется первым, период проверки — 100 мс. Фоновая очередь сохраняет необработанный хвост; получение скриншота не задерживает закрытие.
- Локальная MariaDB запускается независимо от редактора. Старая база в Job редактора перезапускается только после проверки точного executable и файла конфигурации. Чужой процесс с переиспользованным PID не закрывается.
- Причины остановки отображаются понятным текстом на трёх языках. Демо-ярлык использует исправленную сборку.

Проверки:

| Сценарий | Результат |
|---|---|
| Python / desktop / интерфейс | 179 / 24 / 12 пройдено |
| Реальные Electron WebContentsView и отдельный диалог | Основное `isFocused()` ложно; native-проверка принимает собственное окно без остановки |
| Другой процесс с тем же Electron executable | Не признаётся окном экзамена |
| Закрытие трёх собственных тестовых окон | Пройдено; измеряется вызов закрытия, не общая задержка глобального watcher |
| Native lease | Heartbeat поддерживает lease; истечение и повторное освобождение пройдены |
| Локальные Moodle/PHP/TLS/hub | HTTP 200; все четыре проверенных процесса вне Job редактора |
| Содержимое сборки | Desktop, UI, guard EXE/DLL и backend совпадают с подготовленными файлами по SHA-256 |
| Moodle: пять вопросов, обычный прогон | Отправка, автоматическое завершение, start/end сохранены; открытие 5,059 с |
| Moodle: пять вопросов, паузы по 17 с | Отправка, автоматическое завершение, start/end сохранены; открытие 7,601 с |

Машинные результаты: `tests/session-repair-*.json`, `tests/focus-native-acceptance.json`, `tests/guard-acceptance.json`.

Первый длинный E2E потерял соединение автоматизации на четвёртом вопросе. Само приложение осталось активным: после повторного CDP-подключения тест был отправлен, начало и конец сохранены. Этот запуск не считается чистым прохождением сценария автоматизации; отдельный результат сохранён в `session-repair-reconnected.json`. Два последующих Moodle-прогона прошли полностью и имеют отдельные файлы результатов.

Программные Moodle-тесты отключают камеру, микрофон, запись экрана и ограничения ОС в изолированном административном профиле. Проверки native-фокуса не закрывают пользовательские приложения. Полная ручная приёмка Chrome/Edge, Alt+Tab, PrintScreen и USB в реальном защищённом экзамене остаётся отдельным испытанием на ноутбуке пользователя; её нельзя заменять числом пройденных автотестов.

## Қазақша

Сессияның 12,45 секундтан кейін үзілуіне терезе фокусын қате бағалау себеп болған. Moodle ішіндегі қалыпты фокус ауысуы енді Windows-тағы нақты терезе арқылы тексеріледі. Бөгде бағдарлама алдыңғы орынға шықса, алдымен сол процесс қаралады; кезекте қалып қоятын процестер қатесі түзетілді. Қорғаныс шынымен жоғалып, 4 секунд ішінде қалпына келмесе, емтихан тоқтатылады.

Локалды база редактордан тәуелсіз іске қосылады. 179 серверлік, 24 desktop және 12 интерфейс тесті өтті. Нақты Electron терезелері, бөлек процесс, қорғаныс lease-і және үш жеке сынақ терезесін жабу тексерілді. Moodle-дің бес сұрағы екі прогонда толық тапсырылды; тест бетінің ашылуы 5,059 және 7,601 с болды. Нақты Chrome/Edge, пернелер мен USB шектеулерін қолмен тексеру — бөлек қабылдау сынағы.
