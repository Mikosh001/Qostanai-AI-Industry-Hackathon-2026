Жалған маңызды белгілер туралы бастапқы дәлел: пайдаланушы журналында CDN ресурстары `navigation_blocked` ретінде қайталанған; RMS дыбысы үздіксіз эпизодта 15 секунд сайын белгіленген. Енді бұлар тексерілетін оқиға санына қосылмайды. Маңызды жүйелік ақаулар, тұлға/телефон/екінші бет және ұзақ дауыс бақылауы сақталады. JSON толық өзгермейтін журналды сақтайды; PDF тек тексерілетін оқиғаларды көрсетеді.

Физикалық сенсор сынағы дайындықта орындалды: тұлға тіркелмеді, жеке бейне/дыбыс файлға жазылмады. Терезе тесті тек өз терезелерін жабады. Толық Moodle submission үшін әкімшілік бағдарламалық fixture қолданылды; unattended EXE тексерісінде ғана RunAsInvoker пайдаланылды. Нақты іске қосқыш әдеттегі UAC рұқсатын сұрайды.

USB оқу тыйымы/қайтару, жаһандық пернелер/скриншот қорғауы, RDP қызметтерін қайтару, қосымша монитор және secure desktop басқарылатын Windows компьютерінде физикалық сынақты қажет етеді. Университеттің нақты Moodle/Platonus ортасы берілмеген. Осы нәтижелер барлық компьютерде қату болмайтынына немесе барлық әрекет анықталатынына кепіл емес.

Нәтижелер: `tests/release-acceptance.json`, `tests/hardware-smoke.json`, `tests/guard-acceptance.json`. Moodle нұсқаулығы: [MOODLE-QUIZ-GUIDE.md](MOODLE-QUIZ-GUIDE.md). Жаңа тест: **Бағдарламалау негіздері — 5 сұрақ**.
