# Қабылдау сынағы

Автотест пен физикалық құрылғы тексерісі әртүрлі дәлел береді. Төмендегі құрылғы сынақтарын бір басқарылатын Windows компьютерінде алдымен оқшауланған бағдарламалық сынақ профилімен, кейін мұғалім қадағалауымен өндірістік қорғаныста орындаңыз. Жеке ашық құжаттарды жабыңыз, бос сынақ флешкасын қолданыңыз.

| Сценарий | Күтілетін нақты нәтиже | Осы жинақтағы тексеріс |
|---|---|---|
| Бос кадр / модель жүктеу | Модель ready, 0 бет, телефон жоқ | Нақты модельмен өтті |
| Бет және телефон суреті | Реал detector нәтижесі, bbox/confidence | Оң үлгілер өтті; табылмаған телефондар да нәтижеде бар |
| Бастапқы фото | Бір бет → фото сақтау; бағыт қадамдары жоқ; фотосыз тест басталмайды | API және синтетикалық камерадағы UI өтті; физикалық камера сынағы керек |
| Адам ауысуы | Басқа бет ұзақ көрінсе identity_mismatch + бастапқы фото/камера дәлелі | Нақты модель және толық синтетикалық UI өтті; жарық/поза сынағы керек |
| Камера жылдамдығы | Preview AI өңдеуінен бөлек, ескі кадрлар кезекке жиналмайды | Баяу AI стрессі, 10 restart, 28.2 fps синтетикалық және 30.0 fps медианалы физикалық 30 секундтық сынақ өтті |
| Экран дәлелі | Бағдарлама аты/терезесі тіркеледі, экран және камера бөлек ойнатылады | Шифрланған екі жолды автотест және нақты экран capture pipeline-і 5 fps өтті; OS capture protection бөлек физикалық сынақта |
| Телефон көтеру | Қысқа қозғалыстан кейін тұрақты телефон/жоғарғы аймақ оқиғасы + үзінді | Ереже және медиа сақтау автоматты; камерамен сынақ керек |
| Бет жоғалуы/екінші бет | Шектен ұзақ сақталғанда оқиға | Уақыт ережесі автоматты; камерамен сынақ керек |
| Ұзақ төмен/оң/сол қарау | Калибрленген бағыт + ұзақтық; қағаз рұқсат етілсе төмен оқиғасын есептемеу | Ереже автоматты; адаммен сынақ керек |
| Ctrl+T / popup / сайт | Қойынды/сыртқы ресурс ашылмайды; бұғаттау аудитте, оқушыға сайттан шықты деген белгі жоқ; HTTPS домендер ғана | Node policy және нақты Electron Ctrl+T өтті |
| Alt+Tab, Win, PrtScn, Ctrl+C/V | Қатаң режимде native hook бұғаттайды; рұқсат етілген Ctrl+C/V саясаты сақталады | Predicate self-test өтті; OS пернелерімен сынақ керек |
| USB жалғау | WMI оқиғасы; қатаң режимде файл оқылмайды; denial proof тексеріледі | Module жиналды; физикалық флешкамен тексеру керек |
| USB саясаты жоқ | Қатаң емтихан басталмайды | Backend fail-closed өтті |
| Қосымша монитор | Саны/өзгерісі тіркеледі; strict start бір мониторды талап етеді | Код бар; физикалық монитор сынағы керек |
| Бөгде қолданба | Қатаң режимде терезе/тыйым салынған процесс жабылады; алдында экран кадры; сәтсіздікте тест үзіледі | Native модуль өзінің жеке сынақ процесін тоқтатты; нақты терезелермен сынақ керек |
| RDP/қашықтан басқару | RDP сессиясында start қабылданбайды; қызметтер уақытша өшіріледі; белгілі remote процестер жабылады | Start fail-closed автотесті өтті; қызметтер/қайтару оператор сынағында |
| Апаттық шығу | Ctrl+Alt+F12 → шектеулер босайды, сессия interrupted | Код/self-test; физикалық режим сынағы керек |
| Agent process жоғалуы | 10 секундтан кейін guard release; журнал/recovery | Нақты helper: heartbeat 14 секунд ұстап тұрды, probe жаңартпады, 10 секундта release және idempotent release өтті; OS саясатының қайтуы физикалық сынақта |
| Дәлелді өзгерту | AES-GCM бұзылған файлды ашпайды | Автотест өтті |
| Оқиға мәтінін өзгерту | SHA-256 тізбек тексерісі false | Автотест өтті |
| Мұғалім шешімі | Verdict/note сақталып, бастапқы event hash өзгермейді | Автотест өтті |
| Жауап/аяқтау/есеп | Жауап SQLite-да, completed, JSON/PDF | API және Electron өтті |
| Мұғалім режимінен шығу | Cookie жойылады; қайта кіруде пароль керек | Нақты Electron сценарийі өтті |
| Hub HMAC/replay | Жарамсыз key, өткен уақыт, қайталанған packet қабылданбайды | Автотест өтті |
| Remote stop | Хабтың сұрауы агентке келіп, аяқтатады | API маршруты өтті; LAN құрылғы сынағы керек |
| Moodle 4.5.15 | Signed identity, server gating, protected browser, жауап жіберу | Нақты локалды Moodle өтті, камерасыз тест профилінде |
| Университет Moodle | SSO, нақты quiz саясаты, нақты аккаунт | Қолжетімділік берілмеген |
| Университет Platonus | Нақты тестті ашып, жауаптарды жіберу | Қолжетімділік берілмеген |

Пернелерді, флешканы және процесті тексергенде «event тіркелді» мен «әрекет бұғатталды» нәтижесін бөлек жазыңыз. `blocked:false` және `storage_policy_applied:true` нақты бұғатталды деген дәлел емес. USB start үшін `storage_ready:true` қажет: саясат қолданылған, мониторинг тексеруі аяқталған; жалғанған көлемдер оқылмайды. `storage_enforced` тек физикалық denial proof барын бөлек көрсетеді.

Қабылдаудың сәттілігі: бастапқы фото сақталды, басқа адамда оқиға шықты; көрінетін телефон үшін оқиға+үзінді шықты; перне/USB әрекеті шынымен шектелді; заңды емтихан тапсырылып аяқталды; апаттық шығу мен қалыпты шығуда бастапқы Windows жағдайы қайтарылды. Уақыт шектері нақты аудитория/камера сынағы арқылы бапталады.

| Moodle ішіндегі логин | Екінші логинсіз тестке өту, қолтаңбалы user/quiz деректері | Нақты Moodle 4.5.15 + Electron UI сынағы өтті |
| Дыбыс белсенділігі | Дыбыс оқиғасы және тыңдалатын шифрланған WAV; үзілісте тестті тоқтату | Silero: тон/шу/қысқа дауыс оқиғасыз; ұзақ дауыс бір эпизод; шифрлау/ойнату және физикалық микрофон pipeline-і өтті; аудитория шуы бөлек |
| Moodle жауап тапсырылды | Server event → HTTPS hub → агент аяқталуы → Windows шектеулерін босату | Нақты Moodle жауап тапсырылуы және агент автоматты аяқталуы өтті; физикалық OS қайтаруы бөлек тексеріледі |
