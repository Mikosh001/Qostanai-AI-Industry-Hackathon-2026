# Защита от переключения рабочих столов / Жұмыс үстелдерін ауыстырудан қорғау

## Причина и исправление

Трёх- и четырёхпальцевые жесты Precision Touchpad обрабатывает Windows Shell. Они не обязаны проходить через клавиатурный hook. Переход на другой виртуальный рабочий стол убирал защищённое окно с переднего плана; после четырёх секунд без подтверждённого возврата действующая защита корректно останавливала экзамен.

При настоящем Moodle **Start attempt** native guard теперь сохраняет четыре исходные настройки касаний/свайпов, выключает трёх- и четырёхпальцевые действия и обновляет кэш Explorer. Обычный указатель, нажатия и двухпальцевая прокрутка сохраняют свои настройки. Состояние проверяется в реестре и живом кэше до открытия теста и повторно каждые 500 мс. При изменении этих четырёх параметров во время экзамена guard восстанавливает ограничение.

Два native helper не могут владеть общей политикой одновременно: эксклюзивный файловый lease действует для пользователя Windows, независимо от профиля приложения. Общий журнал сбрасывается на диск до изменения настроек. Завершение экзамена, EOF связи, истечение lease и Ctrl+Alt+F12 используют один путь восстановления. Если helper принудительно уничтожен, незавершённый журнал восстанавливается при следующем запуске. Исходные отсутствующие значения остаются отсутствующими. Восстановление подтверждается чтением кэша; при ошибке журнал сохраняется для повтора.

Остановка при действительной потере защиты сохранена. Исправление предотвращает сам путь выхода жестом, а не игнорирует переход на чужой рабочий стол.

## Проверка на ноутбуке

Windows build 26200:

- 179 Python + 27 desktop + 12 browser тестов прошли.
- 14 изолированных проверок gesture policy: rollback, отсутствующие значения, устаревший кэш, повторный release, изменения политики, восстановление из журнала, повреждённый журнал.
- Реальные четыре значения Windows в реестре и кэше: `1/2/1/2 → 0/0/0/0 → 1/2/1/2`.
- Реальный IPC activation с keyboard hook и touchpad policy, без закрытия пользовательских программ, USB и remote policy. Проверяются release, EOF и конфликт второго helper.
- Проверяется реальный путь освобождения настроек при истечении lease.
- В установленном приложении Moodle-экзамен из пяти вопросов отправлен полностью: открытие 4,363 с, время начала и конца сохранено. Это изолированный программный профиль без камеры, микрофона, записи экрана и ограничений ОС; native-защита проверена отдельными испытаниями выше.
- Физический свайп пальцами и полный защищённый Moodle-экзамен требуют ручной приёмки после установки. Программная проверка кэша не называется физическим свайпом.

Результаты: `tests/touchpad-live-cache.json`, `tests/touchpad-ipc-acceptance.json`, `tests/touchpad-package.json`, `tests/touchpad-installed.json`, `tests/touchpad-moodle-acceptance.json`.

## Реализация и воспроизведение

`guard/TouchpadGuard.cs` изолирует недокументированный shell COM adapter. Публичный [TOUCHPAD_PARAMETERS_V1](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-touchpad_parameters_v1) не содержит трёх-/четырёхпальцевых системных жестов. Структура shell interface и исторические идентификаторы описаны автором реализации в [NVDA discussion #19841](https://github.com/nvaccess/nvda/discussions/19841). Для текущей сборки идентификаторы также сверены с бинарным файлом Windows и Microsoft symbols. Другие сборки Windows требуют приёмки: adapter сверяет кэш с реестром и не считает неподтверждённое изменение защитой.

Из обычного PowerShell вне виртуализированного контекста MSIX-редактора:

```powershell
.\build\guard\Sergek.Guard.exe --self-test-gestures
.\build\guard\Sergek.Guard.exe --self-test-gestures-live
node tests/touchpad-live.cjs
```

Последние два теста временно ограничивают жесты; IPC-тест также кратко включает фильтр клавиш. Они восстанавливают настройки и не закрывают другие программы. В MSIX-контексте реестр может быть виртуализирован: реальная shell-проверка должна запускаться независимо, как установленное приложение. Обычный CI использует только изолированный `--self-test-gestures`.

## Қазақша

Windows тачпад қимылдарын перне тіркесімдерінен бөлек өңдейді. Енді Moodle-де тестті бастағанда үш және төрт саусақпен терезе/жұмыс үстелін ауыстыру қимылдары уақытша шектеледі. Қорғаныс Windows-тың өз жадынан тексеріліп барып тест ашылады. Көрсеткіш пен екі саусақпен айналдырудың баптаулары өзгермейді.

Емтихан аяқталғанда, байланыс жабылғанда және апаттық қалпына келтіру кезінде бастапқы төрт баптау қайта орнатылады. Екі қорғаныс процесі бір-бірінің шектеуін алып тастай алмайды. Ноутбукта автоматты тексерістер мен нақты Windows баптауларының қосылуы/қалпына келуі өтті. Саусақпен нақты свайп және толық емтихан — орнатылған жинақтағы қолмен қабылдау сынағы.
